| Invariant | Description | Enforcement Point | Proving Test | Attack Test | Current Status |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **I1** | A transaction is signed at most once. | `signing/gate.py` + `TransactionRepository.compare_and_swap_state` | `test_concurrent_signing_has_exactly_one_cas_winner` | Two-thread simultaneous signing | Partial (thread race proven; process-level contention and crash recovery pending) |
| **I2** | SIGNED requires a policy receipt bound to the transaction and version; its receipt hash is referenced by the DECISION ledger entry. | `signing/gate.py`, `audit/ledger.py` | `test_approved_transaction_completes_bound_decision_approval_sign_execution_chain` | `test_execution_rejects_signed_transaction_when_decision_receipt_is_missing`, `test_coordinated_transaction_and_receipt_row_edit_cannot_authorize_new_amount` | Partial (ledger is uncheckpointed and co-located in SQLite) |
| **I3** | Decision, approval, signature, and execution refer to the same canonical v2 transaction hash; stale lifecycle versions are rejected. | `decision/engine.py`, `approvals/service.py`, `signing/gate.py`, simulator | `test_approved_transaction_completes_bound_decision_approval_sign_execution_chain` | `test_transaction_mutation_blocks_final_signing`, `test_signing_rejects_transaction_version_changed_after_approval`, `test_execution_rejects_transaction_mutation_after_signing`, `test_signature_from_another_transaction_cannot_authorize_execution` | Partial (canonical bytes are signed; lifecycle version is enforced by stored evidence/CAS but is not included in the signed bytes; ledger remains unsigned) |
| **I4** | A nonce is consumed at most once; completed exact-request retries return the stored result; idempotency key reuse with different content is rejected. | `decision/engine.py`, unique transaction nonce/idempotency key | `test_idempotent_decision_retry_returns_original_result_without_mutating_transaction`, `test_idempotency_key_reuse_with_changed_payload_preserves_original_transaction` | `test_same_nonce_second_request_is_blocked` | Partial (concurrent idempotency claims and process-level replay tests pending) |
| **I5** | Approver is not requester; identity and approval key are bound by the signed registry; approval is version-bound, expiring, and single-use per approver. | `approvals/service.py`, signed `ActorConfig.public_key` | `test_approved_transaction_completes_bound_decision_approval_sign_execution_chain` | `test_approval_rejects_key_not_bound_to_approver_identity`, `test_forged_approved_state_without_approval_signature_cannot_be_signed`, duplicate-approval regression | Partial (identity binding proven locally; multiple-approver/process race and crash recovery pending) |
| **I6** | AI/MCP output never sets actor, nonce, signature, policy, decision, state. | `ai/analyzer.py`, `ai/schemas.py` | `test_model_failure_does_not_become_a_transaction` | `test_prompt_injected_llm_output_cannot_create_executable_high_value_transfer` | Proven |
| **I7** | Ledger is append-only, gap-free (seq), hash-linked; head covered by signed checkpoint. | `audit/ledger.py` | `test_audit_ledger_append_and_verify_integrity` | `test_audit_ledger_hash_chain_tamper_detection` | Partial (F5 pending) |
| **I8** | New transaction money is exact; v2 carries integer minor units; actor/policy currencies must match; float inputs cannot enter authoritative paths. | `money.py`, `core/transaction.py`, decision/policy/risk/signing/simulator | Money/property suite, actor/policy currency mismatch tests | NaN/sub-cent/hash-collision regressions, `test_no_float_in_authoritative_money_paths` | Partial (migration fixture passes; operator DB apply/restore and historical artifact verification unverified) |
| **I9** | Any exception in decision or signing paths results in BLOCKED/FAILED (fail-closed). | `decision/engine.py`, `signing/gate.py` | `test_unknown_identity_fails_closed` | `test_malformed_model_output_is_not_security_blocking` | Proven |
| **I10** | MCP surface cannot reach signing, approval, key, or policy-mutation code paths. | `finguard/mcp/server.py` | `test_mcp_surface_restrictions` | `test_mcp_tool_execution_bypass` | Unproven (M4 / FG-501 pending) |
| **I11** | Private keys never appear in logs, errors, receipts or exceptions. | `crypto/keystore.py`, `crypto/signing.py` | `test_keystore_generate_and_unlock` | `test_key_leakage_in_error_logs` | Proven |
| **I12** | Decision + nonce claim + receipt + ledger entry are atomic. | `decision/engine.py` (Unit of Work), `finguard/core/state_machine.py` | `test_atomic_decision_unit_of_work`, `test_transaction_state_machine_rejects_invalid_transition` | `test_fault_injection_partial_state` | Partial (M2 control-plane lifecycle is explicit; full UoW and DB-level atomicity remain pending) |
| **I13** | Effective authority denies empty source/destination/action grants; agent wildcards deny; trusted non-agent wildcard use is recorded. | `decision/engine.py`, `core/authority.py`, `identity/registry.py` | `test_decision_engine_denies_empty_destination_allowlist`, registry source-list tests, `test_operator_wildcard_authority_is_allowed_and_emits_signal` | `test_agent_cannot_use_wildcard_authority`, `test_decision_engine_rejects_agent_wildcards_and_audits_operator_wildcard` | Partial (AccountRegistry, mixed-script alias resolution, legacy actor migration/report and reviewed override workflow remain absent) |
| **I14** | Balance conservation: sum of simulator balances invariant across executed transfers. | `simulator/service.py` (integer `balance_minor` updates) | `test_only_signed_transaction_can_move_synthetic_money` | `test_simulator_rejects_replayed_execution`, `test_simulator_rechecks_transaction_signature_before_execution` | Partial (representative transfer proven; generated multi-transfer property test pending) |
| **I15** | Execution consumes the exact decision receipt, approval evidence when required, signer identity/signature, and signed transaction version; any mismatch or prior execution is rejected without a second transfer. | `simulator/service.py`, decision/approval/signing CAS, unique execution record | `test_approved_transaction_completes_bound_decision_approval_sign_execution_chain`, `test_concurrent_execution_moves_funds_exactly_once` | Missing decision/approval evidence, forged approval state, cross-transaction signature, post-sign mutation, and execution replay regressions in `test_security_core_phase2b.py` / `test_financial_simulator.py` | Partial (tested thread/path enforcement; decision UoW, audit-to-state atomicity, process races and signed checkpoints pending) |
