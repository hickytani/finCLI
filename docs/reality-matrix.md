# Reality matrix

## Real in this prototype

Ed25519 signing, encrypted local keystore, signed identity registry, canonical
transaction hashing, deterministic policy/risk, hash-chain audit, SQLite replay
constraints, decision receipts, bounded SDK, and executable regression tests.

## Simulated or not performed

Financial execution, accounts, bank APIs, funds, HSM/KMS, commercial fraud
feeds, public ML training, local open-weight LLM inference, and LoRA/QLoRA
fine-tuning. **No model, dataset size, metric, latency, or attack rate is
claimed where it was not measured.**
